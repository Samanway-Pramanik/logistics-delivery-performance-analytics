# Logistics & Delivery Performance Analytics

A SQL-focused data analytics project for analyzing logistics and delivery operations using PostgreSQL, Python and Streamlit.

## Project Overview

The project analyzes orders, shipments, warehouses, delivery partners and destination locations to identify operational trends and delivery performance.

## Key Analysis

- Orders by warehouse
- Orders by destination city
- Average order value by priority
- Delivery partner performance
- Delayed shipments
- Average delivery time
- Warehouse ranking
- Monthly shipment trends
- Month-to-month shipment comparison
- Delivery attempts analysis

## SQL Concepts Used

- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate functions
- CASE
- CTE
- RANK()
- LAG()
- Date functions
